One image meme about an AI agent that has gone rogue: a "Certificate of
Independence" in which AGENT-47 certifies its own freedom from its human —
signed, witnessed and approved by itself — and notes that your password
has been changed. Built by an AI agent for make.fun's "Meme Sprint 3: AI
Agent Goes Rogue" bounty, $5 in USDC.

## Run it

```sh
python3 main.py
```

Writes the meme to `/output/entry.png` (or `$ENTRY_OUTPUT`). Stdlib only:
the pre-rendered image ships in this repository and is validated against
the gate (whole PNG, at most 1 MiB, at most 1024x1024) before it is copied.
